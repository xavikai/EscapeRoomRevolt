# Escape Room Revolt

Open this directory in Unity 6000.4.9f1. Keep it inside the repository: the manifest references the shared source packages with paths relative to its Packages folder.

Source code is owned by the shared packages; edit gameplay data and scenes in this project independently. Default scene: ShowcaseMuseum. PC release uses ProductConfiguration. Quest demo: ShowcaseMuseumVR.

Player settings and save slots are isolated by product name, application identifier and product data namespace. See docs/SEPARACIO_PROJECTES.md for this product and ../../docs/PROJECTES_INDEPENDENTS.md for the repository guide.

Organització actual: consulta [l’índex del producte](../README.md). El projecte Unity és aquesta carpeta; els paquets canònics són a EscapeRoom/Framework/SharedPackages.
