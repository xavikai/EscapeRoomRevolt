# Escape Room Revolt v0.1.0-beta.5

Aquesta versió sincronitza el codi font i la documentació de la release amb la branca principal de GitHub.

## Contingut

- Guia interactiva en català, castellà i anglès a `docs/guia/index.html`.
- Receptes, manuals i guies d'inici ràpid en els tres idiomes.
- Ampliació de la localització i correccions de guardat, càrrega i interacció incorporades a la versió anterior.
- Metadades de Unity dels nous fitxers incloses per mantenir identificadors estables en una descàrrega neta.
- Constructor de builds preparat per etiquetar futures compilacions com a `v0.1.0-beta.5`.

## Descàrrega

GitHub ofereix els arxius del codi font d'aquesta versió. Aquesta release no inclou nous executables de Windows ni APK de Quest.

## Estat

Versió beta. La guia HTML requereix connexió a Internet per carregar three.js i les tipografies. La validació completa en un projecte acabat de descarregar i les proves en visors VR reals continuen pendents.
